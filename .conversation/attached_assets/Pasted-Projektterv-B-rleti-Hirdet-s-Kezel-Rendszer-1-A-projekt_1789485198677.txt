Projektterv – Bérleti Hirdető és Kezelő Rendszer
1. A projekt célja
A projekt célja egy modern, webes bérleti rendszer megvalósítása, amely támogatja:
ingatlanok hirdetését
bérbeadók ingatlankezelését
bérlők böngészési és kapcsolatfelvételi lehetőségeit
karbantartási kérések és dokumentumok kezelését
közös kommunikációt és naptárkezelést
bérleti díjak követését és emlékeztetők küldését
A rendszer moduláris, bővíthető, és korszerű webes technológiákra épül.

2. Felhasználói szerepkörök
2.1 Bérlő
A bérlő képes:
hirdetéseket keresni és megtekinteni
kapcsolatba lépni a bérbeadóval
karbantartási kérelmet küldeni
dokumentumokat, képeket feltölteni a naptárba
saját bérleti díjai státuszát követni
2.2 Bérbeadó
A bérbeadó képes:
ingatlanokat rögzíteni, módosítani, hirdetni
bérlői kérelmeket kezelni
karbantartási feladatokat adminisztrálni
dokumentumokat feltölteni és kezelni
értesítéseket fogadni valós időben
teljes bérleti folyamatot menedzselni

3. A rendszer architektúrája
A projekt három modern technológiai réteg együttműködésére épül:
3.1 Angular frontend
A felhasználói felületet Angular 17 biztosítja:
gyors, reszponzív Single Page Application
Material Design vagy TailwindCSS
JWT alapú bejelentkezés
REST + GraphQL kommunikáció támogatása
valós idejű adatok WebSocketeken keresztül
3.2 Spring Boot backend
A szerveroldali logikát Spring Boot 3 biztosítja:
REST API (fő adatműveletekhez)
GraphQL (összetett, aggregált adatlekérésekhez)
JPA / Hibernate (adatbázisréteg)
WebSocket értesítések
Spring Security + JWT (biztonság)
3.3 Adatbázis
Fejlesztéshez: H2
Éles környezet: PostgreSQL vagy MySQL

4. Fő funkcionális modulok
4.1 Hirdetési modul
ingatlan hirdetések létrehozása, törlése, szerkesztése
hirdetési képek feltöltése
keresés, szűrés, rendezés
4.2 Ingatlan kezelő modul (bérbeadó)
saját ingatlanok listázása és menedzselése
hirdetési állapotok kezelése
4.3 Naptár modul (közös bérlő–bérbeadó)
események rögzítése (pl. hibák, ellenőrzések, fizetések)
dokumentumok + képek feltöltése
fiókonként szűrhető naptár nézet
GraphQL aggregáció: ingatlan → naptár → dokumentumok
4.4 Karbantartási modul
kérések beküldése (bérlő)
jóváhagyás / elutasítás (bérbeadó)
állapotkövetés
4.5 Bérleti díjak kezelése
fizetési státusz nyilvántartása
automatikus emlékeztetők
dokumentumfeltöltés (bizonyítékok)
4.6 Üzenetküldés / kommunikáció
WebSocket alapú chat
értesítések: új karbantartási kérelem, feltöltött dokumentum stb.

8. REST API minták
Példák:
Felhasználó
POST /api/auth/login
POST /api/auth/register

Hirdetések
GET /api/listings
POST /api/listings
PUT /api/listings/{id}

Naptár
GET /api/calendar/{propertyId}
POST /api/calendar


9. GraphQL modul (összetett lekérdezésekhez)
